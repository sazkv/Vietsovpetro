# Vietsovpetro — independent website redesign concept

An unofficial, independent concept for modernizing the public Vietsovpetro website. Not affiliated with or endorsed by Vietsovpetro.

## Principles
- Preserve existing public sections, content, documents and external service links.
- Treat the Vietnamese-language official website as the primary reference, while verifying facts and keeping translation status explicit.
- Corporate industrial visual language; no generic AI gradients or decorative 3D.
- Accessible, responsive, lightweight, and maintainable.
- No simulated employee login or collection of actual applicant information.

## Current scope
A first functional front-end foundation with responsive navigation and clear placeholders for sections that still require content inventory. Nothing is represented as an official Vietsovpetro service.

## Run
```bash
npm install
npm run dev
```

Open http://localhost:3000.
