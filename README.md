# Vietsovpetro — редизайн сайта

Независимая демонстрация нового интерфейса на основе опубликованного содержания [vietsov.com.vn](https://www.vietsov.com.vn/Pages/default.aspx). Проект не является официальным сайтом компании.

## Что входит

- Главная страница с исходными баннерами, услугами, новостными рубриками и проектами.
- Оригинальные логотипы и фотографии Vietsovpetro.
- Страницы разделов и материалы с исходными текстами, датами, таблицами, ссылками и изображениями.
- Вьетнамская, русская и английская версии. Интерфейс переключается через `next-intl`; для каждой версии используются опубликованные на исходном сайте материалы соответствующего языка.
- Адаптивная светлая вёрстка, меню для телефона и планшета, анимация перехода между исходными баннерами с учётом `prefers-reduced-motion`.

Содержимое хранится в `src/data/original-pages.json` и `src/data/home-content.json`. В каждом материале сохранён `sourceUrl`. Изображения внутри архивных материалов загружаются с исходного сайта.

## Разработка

Node.js 22 или новее:

```bash
npm ci
npm run check:structure
npm run dev
```

Статическая сборка:

```bash
npm run build
```

GitHub Pages собирает `out/` через `.github/workflows/pages.yml`. Для сборки по адресу репозитория задаются `NEXT_PUBLIC_BASE_PATH=/Vietsovpetro` и `NEXT_PUBLIC_SITE_URL=https://sazkv.github.io/Vietsovpetro`.

## Источник и границы переноса

Каталог собран из публичных страниц сайта Vietsovpetro. При добавлении материалов нужно сверять текст, ссылки, дату и изображения с исходной страницей. Подробности текущего охвата и проверки находятся в [docs/REDESIGN_AUDIT.md](docs/REDESIGN_AUDIT.md).
