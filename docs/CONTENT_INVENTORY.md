# Vietsovpetro — инвентаризация оригинальных материалов

Проект является независимой концепцией. Официальный первоисточник: https://www.vietsov.com.vn/Pages/default.aspx.

## Текущее покрытие

`src/data/original-pages.json` содержит 2 360 публичных страниц: 2 096 VI, 213 RU и 51 EN. Для каждой записи сохранены исходный URL, язык, маршрут, заголовок, HTML, дата публикации при наличии и адреса изображений. Основные разделы: компания, подразделения, услуги, новости, проекты, ресурсы, карьера и контакты. Доступные полные тела новостей сохранены в 2 237 статьях раздела `news` (плюс три страницы указателей). Проверка маршрутов и локальных ссылок — `npm run check:structure`.

`src/lib/site-map.ts` сохранён как ранний реестр соответствия разделов и исходных URL. Актуальная постраничная карта маршрутов находится в `src/data/original-pages.json`; реестр не заменяет полный экспорт. В `src/data/page-labels.json` находятся только читабельные подписи для страниц, у которых заголовок исходного HTML был служебным именем. Исходные заголовки не меняются.

## Неполные зоны

- На официальном сайте услуги опубликованы единым каталогом из 15 названий и изображений. Отдельных полных страниц с техническими характеристиками для каждой позиции в исследованном источнике нет. В концепции они не представлены как завершённые карточки услуг.
- Проекты опубликованы как пять направлений с таблицами выполненных работ. Отдельные записи проектов, галереи и документы пока не выделены из таблиц. Таблицы на страницах направлений сохранены полностью.
- Страница организационной структуры в доступном HTML содержит только краткий текст; оригинальная схема подразделений не извлечена. Каталог подразделений ведёт на 16 доступных профилей, но исходные версии указывают разные числа подразделений в разные годы.
- Расписание полётов (`LichBay.aspx`) динамическое; оставлена ссылка на официальный сервис. Авторизованные корпоративные системы не копируются.
- Часть изображений и вложений остаётся на домене первоисточника. Нужна проверка лицензий и редакторская приёмка перед передачей компании.
- Русский и английский оригиналы значительно меньше вьетнамского. Новые переводы материалов не создавались; переключатель языка ведёт на доступный раздел.

Не считать страницу полностью редакционно перенесённой, пока не проверены вложения, медиа, факты, актуальность и права на публикацию.
