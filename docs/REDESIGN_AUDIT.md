# Аудит и редизайн Vietsovpetro

Дата: 24 октября 2026. Репозиторий: [sazkv/Vietsovpetro](https://github.com/sazkv/Vietsovpetro). Это независимый концепт, не официальный сайт компании.

## Что проверено

- Структура: 8 разделов, 60 записей каталога, 17 внешних системных ссылок. Маршруты `/[section]/[slug]` сохранены.
- Контент: полный текст большей части страниц, файлы, таблицы и медиа ещё не перенесены. Проект честно показывает статус и источник.
- Сборка: Next.js со статическим экспортом. До исправления `robots.ts` и `sitemap.ts` production build падал при `output: "export"`.
- Адаптивность: исходная навигация была перегружена на средних экранах; новый вариант проверен на десктопе, планшетном и мобильном брейкпоинтах.
- Публикация: репозиторий открыт. Стандартные GitHub-hosted runners для публичных репозиториев, по документации GitHub, не расходуют платные минуты.

## Выявленные проблемы исходной версии

1. Главный экран зависел от внешней фотографии Vietsovpetro без оформленного разрешения на повторное использование.
2. Навигация выводила все разделы и глубокие выпадающие списки в одной строке; мобильные вложенные разделы были трудны для поиска.
3. Почти все основные блоки были одинаковыми прямоугольными карточками без выраженной типографической иерархии.
4. На главной выводились показатели 18 единиц и 250+ млн тонн, которые документация самого проекта требует перепроверить.
5. Каталог услуг содержал фразу на русском языке в основном вьетнамском тексте.
6. Статический экспорт с существующими динамическими metadata routes не собирался.

## Что изменено

- Светлая палитра с глубоким морским синим и красным акцентом, вдохновлённая [официальными материалами Vietsovpetro](https://www.vietsov.com.vn/LichBay/Flipbook/CamNangVH.pdf); точные брендовые коды не заявляются. Типографика Cabinet Grotesk с системным fallback.
- Главный экран с иллюстративной SVG-сценой морской платформы и сервисного судна. Графика не изображает конкретный объект и не требует чужих фото.
- Все 8 разделов доступны из навигации, мобильного меню и футера.
- Сохранён порядок смысловых блоков главной: цифры, введение, направления, проекты, новости, карьера, быстрые ссылки.
- Добавлены GSAP анимации сцены, закрепление заголовка проектов и появление/наложение проектных панелей. Для `prefers-reduced-motion` анимации отключены.
- Сетка направлений занимает 3 × 2 ячейки без пустот; интерактивные области услуг раскрываются горизонтально на больших экранах и становятся списком на телефоне.
- Настроен base path для GitHub Pages, добавлен workflow статической сборки.

## Проверка

- `npm run check:structure`: успешно, 8 групп / 60 страниц / 17 внешних ссылок.
- `npm run build`: успешно, 76 экспортированных страниц.
- Ручная проверка: десктоп, планшетный и мобильный брейкпоинты; меню, каталог, фильтр; горизонтального переполнения на узком экране нет.

## Что остаётся до официального сайта

Полный перенос статей, проектов, архивов, вложений и переводов; сверка числа подразделений; юридическое разрешение на фирменные материалы и изображения; редакторская проверка контактных и новостных данных; подключение настоящего CMS. Эти задачи не подменяются текстом концепта. Развёртывание на GitHub Pages публикует только независимую демонстрацию с `noindex`.
