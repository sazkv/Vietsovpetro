# Аудит редизайна Vietsovpetro

24 октября 2026 года. Источник: публичные страницы [vietsov.com.vn](https://www.vietsov.com.vn/Pages/default.aspx). Репозиторий остаётся независимой демонстрацией.

## Содержание

По внутренним ссылкам действующего сайта просмотрена 2 361 доступная страница на трёх языках. Для одной динамической страницы расписания рейсов (`LichBay.aspx`) содержимое не подходит для статического экспорта; в интерфейсе оставлена прямая ссылка на оригинал. Остальные 2 360 страниц перенесены в `src/data/original-pages.json` со ссылкой `sourceUrl` на каждый источник.

| Язык | Страницы | Новостные материалы |
| --- | ---: | ---: |
| Вьетнамский | 2 096 | 2 051 |
| Русский | 213 | 173 |
| Английский | 51 | 13 |

На главных страницах каждого языка сохранены 15 услуг, три новостные рубрики и пять проектов. Тексты, даты, таблицы, фотографии и ссылки в материалах взяты с соответствующих страниц оригинала. Оригинальный сайт публикует разное количество материалов на разных языках; проект сохраняет именно эти версии и не создаёт новые переводы статей.

Изображения внутри архивных материалов остаются по адресам оригинального сайта. Их доступность зависит от `vietsov.com.vn`. Баннеры и логотипы для шапки сохранены локально в `public/brand/`.

## Интерфейс

- Удалены иллюстрированная сцена, вымышленный логотип, редакционные заглушки и служебные подписи старого концепта.
- Структура верхнего меню и разделов соответствует текущему сайту. Внешние корпоративные сервисы оставлены ссылками на исходные системы.
- Светлая палитра использует синий и красный цвета исходной айдентики. Услуги оформлены типографическим списком, новости и проекты используют исходные изображения.
- На широком экране переключаются исходные баннеры; на узком экране видна исходная фотография и текст оригинального баннера. Переходы отключаются при `prefers-reduced-motion`.
- Интерфейс VI/RU/EN работает через `next-intl`.

## Проверки

- `npm run check:structure`: количество услуг и разделов главных страниц, уникальность маршрутов и источников, наличие заголовка и текста, отсутствие опасной разметки, наличие локальных маршрутов новостей.
- `npm run build` с настройками GitHub Pages: статический экспорт всех маршрутов.
- Ручная проверка главной и статьи в браузере: исходные логотип, баннер, заголовок, дата, таблица и изображения отображаются.

Статический экспорт не воспроизводит авторизованные сервисы и динамические функции SharePoint. Их опубликованные ссылки ведут на оригинальный сайт.
